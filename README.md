# 🎓 AI-Based Student Academic Performance Assistant

## 📌 Project Overview

The **AI-Based Student Academic Performance Assistant** is a chatbot-based application designed to help students understand and improve their academic performance. It provides students with academic guidance, performance-related insights, and answers to their queries using AI.

## 🎯 Objectives

* Help students understand their academic performance.
* Provide personalized academic guidance.
* Answer student-related academic queries.
* Assist students in identifying areas for improvement.
* Provide a simple and interactive chatbot interface.

## 🛠️ Technologies Used

* **Python**
* **Streamlit**
* **Ollama**
* **AI / LLM**
* **Git & GitHub**

## ✨ Key Features

* Interactive AI chatbot
* Student academic assistance
* Simple and user-friendly interface
* AI-based responses
* Easy to run locally

## 🚀 How to Run

### 1. Create a virtual environment

```bash
python -m venv venv
```

### 2. Activate the virtual environment

```bash
venv\Scripts\activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the application

```bash
streamlit run app.py
```
